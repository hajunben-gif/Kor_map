# 부여군·청양군 통합 2km 도로망 검증

## A. 완료 및 미완료

통합 PBF 추출·그래프 구축·시설 비교 코드를 구현했습니다. 보존된 실제 죽림리 OSM 자료로 국소 도로망을 재구축하고, 기존 147개 입력 행의 복합키·좌표 및 정밀 접근거리를 대조했습니다. 합성 PBF로 146개 시설 재계산과 GraphML·GeoPackage·CSV 생성 및 재로딩을 검증했습니다.

2026-11-19 실행 환경에는 전국 PBF 원본이 없었습니다. Geofabrik 과거 파일과 최신 파일·공식 MD5 확인 요청은 Cloud 프록시에서 HTTP 403으로 차단됐습니다. 연결이 허용된 Overpass에도 실제 국소 쿼리가 HTTP 406으로 실패했습니다. GitHub 릴리스와 확인한 기존 PBF 감사 실행 4건에 원본이 없었습니다. 실제 통합망 GraphML·GeoPackage와 146개 시설의 새 거리·이상치 결과는 전국 PBF 확보 후 실행해야 합니다.

## B. 범위·출처 및 도로망 통계

기존 EPSG:5179 통합 2km 폴리곤 **1,481.032km²**를 사용합니다. 전체 OSM way의 투영 선형이 이 폴리곤에 닿으면 원본 노드와 선형 전체를 포함합니다. 꼭짓점이 모두 외부인 관통 선형도 포함합니다. 군 경계는 비교에 사용하며, 그래프 추출은 통합 폴리곤 한 번을 기준으로 처리합니다. 외곽 바깥에만 있는 drive way가 보존 노드와 공유하는 접점은 별도로 기록합니다. 교차 지점에 실제 공유 OSM 노드가 있을 때 연결합니다.

## F. 미해결 및 다음 단계

보존된 SHA-256과 일치하는 전국 PBF를 작업 환경에 연결한 뒤 아래 명령을 실행합니다. 다른 PBF를 사용할 경우 검증한 SHA-256과 출처를 별도로 지정하며, 기준 시각 차이를 결과와 함께 남깁니다. 통합 결과가 나오면 잔존 이상치의 OSM 태그와 원본 노드, 개곡리 좌표를 독립 자료와 대조합니다. 거리 임계값은 검토 기준이며 실제 구호차량 통행 가능성은 현장 확인이 필요합니다.

## G. 파일·테스트·실행 명령

`origin/main`의 `da5931e`에서 별도 `integrated-road-network` 작업 트리를 생성했습니다. 새 구현은 `scripts/build_integrated_road_network.py`, `scripts/integrated_road_graph.py`에, 새 테스트는 `tests/test_integrated_road_network.py`에 있습니다. 이 디렉터리의 JSON 두 개는 실제 보존 국소 자료 및 과거 캐시로 각각 실행한 결과입니다.

전체 테스트 **54개와 하위 테스트 10개**를 통과했습니다. 기존 죽림리 오프라인 회귀 6개 설정을 재현했습니다. 합성 PBF로 두 끝점이 외곽인 관통 도로, 경계 밖 공유 노드, 교차하지만 공유 ID가 없는 도로, 역방향 일방통행, 양방향 거리 중복, 입력 누락·손상, 146개 매칭, 신규 이상치와 파일 재로딩을 검증했습니다. 작업 시작 시 추적된 기존 파일 111개의 SHA-256이 유지됐습니다.

실제로 실행한 명령입니다. 다운로드 시도는 종료 코드 1을 반환했고 지정한 결과 디렉터리가 생성되지 않았습니다. 오프라인 재실행 시 새 출력 경로를 지정합니다.

```sh
python -m pip install -r requirements-pbf-audit.txt
python -m pytest -q
python scripts/jukrim_boundary_regression.py \
  --output output/integrated_road_network/offline_validation/jukrim_historical_regression.json
python -m scripts.build_integrated_road_network --replay-jukrim \
  --output output/integrated_road_network/offline_validation/jukrim_local_replay.json
python -m scripts.build_integrated_road_network --download-latest \
  --output /workspace/work/attempted-integrated-latest
```

원본 확보 후 실행할 명령입니다. 다른 날짜의 로컬 PBF는 `--sha256 <검증된 SHA-256> --source <출처>`로 명시합니다. 실제 결과에는 원본·단순화 GraphML, 노드·간선 4개 레이어의 GeoPackage, 메타데이터, 시설 비교·기존 이상치·신규 이상치 CSV, 죽림리 JSON과 한국어 보고서가 포함됩니다.

```sh
python -m pip install -r requirements.txt -r requirements-pbf-audit.txt
python -m scripts.build_integrated_road_network \
  --pbf /path/to/south-korea-261109.osm.pbf \
  --output output/integrated_road_network/20261109_snapshot
```
