# 접근거리 300m 초과 6곳 원인 조사

**청양군 그래프 내부에서는 6곳 모두 저장된 최근접거리 계산이 맞습니다. 다만 죽림리회관은 기존 부여군 지천로까지 259.89m로 더 가까워, 청양군만 검색한 범위 제한의 영향을 확인했습니다. 실제 진입로·통행 가능성은 여전히 확정하지 못했습니다.**

6곳 모두 국소 도로자료 대조가 필요합니다. 원본 CSV·좌표·GraphML과 전체 146곳의 기존 결과는 변경하지 않았습니다.

## 공통으로 확인된 사실

- 6개 시설의 원본 위도·경도, 선택된 `(u,v,key)`, 저장 최근접점이 일관됩니다. 이 6곳만 대상으로 모든 기존 간선까지의 거리를 검산했고 더 가까운 기존 drive 간선은 없었습니다.
- 입력 주소와 저장된 Kakao 반환 주소가 모두 일치합니다. 죽림·남천·지곡·덕성1·천장은 회관과 일관된 건물명이 반환됐고, 개곡은 건물명 공란입니다. 독립적인 현장 확인을 뜻하지 않습니다.
- OSMnx 2.1.1의 기본 drive 필터는 **highway=service 자체**와 track, footway, path, access=private 등을 제외합니다. 기존 추출 코드와 버전 메타데이터로 필터 정책을 재현했습니다.
- retain_all=True여서 최대 WCC만 남기는 설정으로 작은 연결요소를 통째로 버린 사례는 아닙니다. 선택 간선은 모두 최대 WCC에 속합니다.
- 기존 프로젝트 자료와 제공 ZIP에는 제외 도로를 비교할 범용 원시 OSM/비절단 도로망이 없습니다. 따라서 더 가까운 제외 도로가 실제 존재하는지, OSM에 미매핑된 도로인지 구분할 수 없습니다.

- 추가로 기존 부여군 drive 그래프를 대상 6곳에 한정해 대조했습니다. **죽림리회관에서 기존 지천로까지 259.89m**이며, 그 도로점은 청양군 경계 밖에 있습니다. 해당 간선 키는 청양군 그래프에 없습니다. 나머지 5곳은 부여군 기존 도로가 2km 이내에 없었습니다. 공주시 등 다른 인접 지역의 도로망은 없어 확인하지 못했습니다.

- **판정:** 기존 그래프 기준 장거리라는 사실은 유효합니다. 정상적인 실제 장거리 진입 사례로 확정할 수 없으며, 도로를 추가할지 판단하기 전에 해당 위치의 국소 범용 OSM·독립 도로자료를 대조해야 합니다.

## 해석과 다음 판단에 필요한 증거

1. 죽림은 기존 인접 군 도로가 259.89m에 있음을 확인해 군별 검색 범위의 영향이 입증됐습니다. 남천은 경계까지 76.42m이나 대응 인접 군 도로망이 없어 외부 도로 존재는 확인 불가입니다. 경계가 가깝다는 사실만으로 절단 원인이 입증되지는 않습니다.
2. 개곡·지곡·덕성1·천장은 현재 접근거리 범위가 경계 내부입니다. 경계 밖에만 있는 도로의 제외만으로는 거리를 설명할 수 없습니다. 다만 경계를 넘는 간선이 통째로 삭제됐을 가능성까지 완전히 배제하지는 못합니다.
3. 네트워크 보완 여부는 6곳 주변 2km의 범용 OSM에서 service/track/access 태그와 도로 형상을 확인하고 독립 영상·도로자료와 비교한 뒤 결정해야 합니다. 본 조사에서는 새 도로를 내려받거나 추가하지 않았습니다.
4. 개곡리회관은 반환 건물명도 없어 시설 자체 위치를 독립적으로 확인할 우선 대상입니다. 나머지 5곳의 건물명 일관성도 현장 검증의 대체가 아닙니다.

## 지도·보존

- 지도는 **시설 중심 반경 2km (전체 폭 약 4km)**입니다. 빨강=원본 시설, 파랑=저장 선택 간선, 초록=저장 최근접점, 보라 점선=기존 직선거리 표시입니다. 점선을 실제 도로로 해석하면 안 됩니다.
- 주황은 기존 OSM 행정경계입니다. 최근접 경계점·보조선은 경계가 2km 이내인 경우 선택 레이어로 제공합니다.
- 죽림 지도에는 갈색으로 기존 부여군 도로와 비교 최근접점·거리 보조선을 추가 표시했습니다. 새 도로 또는 대체 연결로 추가한 것이 아니며 원본 저장 최근접점은 초록으로 유지했습니다.
- 표시용으로만 간선을 2km 원과 교차시켰습니다. GraphML에는 노드·간선·가상 연결선을 추가하지 않았습니다.
- 배경 OSM 타일은 현재 온라인 참고자료이며 도로 제외 여부의 확인 증거로 사용하지 않았습니다. 지도 HTML의 타일·라이브러리는 인터넷이 필요합니다.
- 거리 계산은 EPSG:5179, 지도 표시는 EPSG:4326입니다. 기존 OSM 행정경계는 공식 측량 경계와 동일함을 보장하지 않습니다.
- 보고서 JSON에 입력 SHA-256, 원본 좌표/간선, 저장된 API 증거 출처, 사실·가설·판정, 원본 보존 검증을 기록했습니다.
- 원본 좌표, 최종 CSV, 2단계 분석 CSV, GraphML 및 모든 기존 추적 파일이 변경되지 않았음을 바이트 단위로 확인했습니다.

검증: 대상 6곳의 저장 간선·최근접점·거리와 경계 거리 검증을 통과했습니다. 상세 지도 6개에서 원본 시설 좌표·저장 최근접점·점선을 브라우저로 확인했습니다. 지도 라이브러리는 공식 CDN의 로컬 캐시를 사용했고 배경 타일은 검증 중 비활성화했습니다. 기존 추적 파일 54개는 모두 바이트 단위로 동일합니다.
