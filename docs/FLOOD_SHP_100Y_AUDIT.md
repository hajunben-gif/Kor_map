# 100년 빈도 하천범람 SHP 원본 검증 (부여·청양)

## 목적
사용자가 확보한 100년 빈도 4개 공간데이터의 실제 DBF 필드명·고유값·좌표계·도형 기록 수를 검증한다. **필드명과 침수심 등급의 관계를 확인하지 않고 차단 기준을 자동 설정하지 않는다.**

| 대상 | 원본 파일명 (확장자 생략) |
|---|---|
| 부여군 국가하천 | `RFM_SGG_NTN_44760_100` |
| 부여군 지방하천 | `RFM_SGG_RGN_44760_100` |
| 청양군 국가하천 | `RFM_SGG_NTN_44790_100` |
| 청양군 지방하천 | `RFM_SGG_RGN_44790_100` |

각 세트의 `.shp`, `.shx`, `.dbf`, `.prj`, `.cpg`를 **같은 폴더**에 두고 다음 명령을 실행한다. 원본 20개 파일은 읽기만 하며 변경하지 않는다. GitHub에 원본 데이터를 커밋할 필요는 없다.

```bash
python scripts/audit_flood_shp_100y.py \
  --input-dir /path/to/flood_100y_sources \
  --output-dir /path/to/flood_100y_audit_out
```

출력은 `flood_shp_audit_100y.json`과 `flood_shp_audit_100y.md`이다. 이 보고서에는 파일별 SHA-256, DBF 컬럼과 고유값의 빈도, SHP/SHX/DBF 레코드 수, CRS, SHP 범위가 들어간다.

`geopandas`가 설치되어 있으면 추가로 유효하지 않은 폴리곤 개수, 비어 있는 도형 개수, 피처 면적 합계(중복 제거 전)를 계산한다.

```bash
pip install geopandas
```

**해석 유의사항**
- SHP에 침수심이 실제 측정 수치(예: m)인지 등급 코드인지는 필드명만으로 확정할 수 없다. DBF 값과 공식 침수심 범례·자료명세서를 대조해야 한다.
- SHP 투영좌표계는 파일의 `.prj`를 검사한다. EPSG:5186으로 확인되면 도로망과의 거리를 계산할 때 EPSG:5179 등 적절한 미터 단위 좌표계로 재투영한다.
- 각 SHP 파일에서 5개 레코드가 나오더라도 이는 5개 침수심 등급의 증거가 아니라 **구조적으로 5개 도형 기록이 존재한다는 의미**뿐이다.
- 4개 자료의 국가/지방하천 중복 부분, 침수심 해석, 교량·고가도로 고도 문제, 도로망 중첩은 **이번 검사에 포함되지 않는다.**
- S0(차단 없음), S1(낮은 수심 등급 유지), S2(모든 침수구역 차단) 등은 아직 최종 확정하지 않는다. 필드·단위·등급 확인 후 실제 기준과 비교해야 한다.
