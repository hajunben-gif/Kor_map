# 100년 빈도 침수심 `SEG_CODE` ↔ 침수심 등급 정의

부여군·청양군 국가·지방하천 100년 빈도 SHP 원본의 `SEG_CODE`를 해석하기 위해 확보한 코드표와 근거를 정리한다.

## 출처

- [홍수위험지도 정보제공포털 — 국가하천 범람지도 API 명세서, NationalMap-watershed](https://data.floodmap.go.kr/main/guide/api_reference?map=nationalRiverFloodMap#NationalMap-watershed)
- 항목명: `SegCode`
- 사용자 제공 명세 내용 (2026-11-23): `N330 : 침수심 0.5m 미만`, `N331 : 침수심 0.5 ~ 1.0m`, `N332 : 침수심 1.0 ~ 2.0m`, `N333 : 침수심 2.0 ~ 5.0m`, `N334 : 침수심 5.0m 이상`
- **검증 상태:** 해당 공식 URL은 자동 웹 접속에서 시간 초과되어 본문을 직접 재확인하지 못했음. 사용자 제공 공식 명세 발췌에 기반함. 공식 문서 캡처·다운로드본을 출처 증빙으로 보존할 것.

| 원본 `SEG_CODE` | 침수심 등급 |
|---|---|
| `N330` | 0.5m 미만 |
| `N331` | 0.5 ~ 1.0m |
| `N332` | 1.0 ~ 2.0m |
| `N333` | 2.0 ~ 5.0m |
| `N334` | 5.0m 이상 |

명세서 범위 표현만으로 각 구간 경계값의 포함/제외는 완전히 결정되지 않는다. 도로 차단은 **수치 보간이 아닌 `SEG_CODE` 집합 선택**으로 정의한다.

## 차단 민감도 분석 (차량 안전 기준이 아닌 연구 시나리오)

| 시나리오 | `SEG_CODE` 제거 | 목적 |
|---|---|---|
| S0 | 없음 | 평상시 도로망 기준 |
| S1 | N331, N332, N333, N334 | 0.5m 미만 등급은 통행 가능한 것으로 가정한 상대적으로 완화된 차단 |
| S2 | N330, N331, N332, N333, N334 | 침수구역과 교차한 모든 도로 구간을 차단하는 보수적 가정 |

`N330` 등급은 수심이 0m라는 뜻이 아니다. 침수심 0.3m 기준을 `N330` 구간 안에서 정확하게 판정할 수 없다.

## 기술적·방법론적 제한

1. 국가하천 공식 API 명세를 통해 코드표를 확인했으며, **지방하천 SHP도 동일한 `N330~N334` 코드를 사용**하는 것이 4개 SHP의 DBF 검사로 확인됐다. 다만 API 명세서가 국가하천 대상이므로 지방하천의 동일 의미는 지방하천 메타데이터나 공식 이미지와 교차검증하면 더 엄밀하다.
2. 좌표변환 및 기하 오류 보정은 침수심 코드 정의와 무관하다. 처리 시 원본 보존, 보정 전후 면적, 보정 대상 도형을 검증 보고서로 남긴다.
3. 국가·지방하천 100년 빈도 범람구역의 합집합은 하나의 실제 100년 홍수 사건을 의미하지 않는다.
4. 교량·고가도로는 평면상 침수구역과 겹쳐도 도로 노면이 잠겼다고 단정할 수 없다.
5. 최종 차단 도로/시설 연결성은 공간 중첩·위상 QA가 끝난 뒤 계산한다.

기계 판독 가능한 사전은 [config/flood_seg_code_100y.json](../config/flood_seg_code_100y.json)에 보존한다.
