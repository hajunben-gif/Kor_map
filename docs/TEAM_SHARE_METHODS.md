# 부여·청양 침수 도로망 연구 방법

## 기본 도로망과 프로파일

Geofabrik의 OpenStreetMap 스냅샷에서 부여군·청양군 분석영역의 도로를 추출했다. 원본 OSM way, 방향, 선분 순번을 보존해 그래프를 단순화했으며, 접속 가능한 OSM 노드에서만 다른 간선으로 이동한다. 분석 길이와 면적의 좌표계는 EPSG:5186이다.

| 도로 프로파일 | 범위 |
|---|---|
| `drive_reference` | 일반 차량용 기준망 |
| `drive_service` | 일반 차량망에 서비스 도로를 더한 비교망 |
| `relief_vehicle_candidate` | 서비스 도로 포함망에서 명시적 차량 제한을 반영해 선별한 구호차량 후보망 |

HTML은 `relief_vehicle_candidate`를 표시한다. 시나리오 비교 CSV에는 세 프로파일이 들어 있다. 후보망은 통행 허가와 차량 제원을 현장 확인한 결과와 구분한다.

## 침수 시나리오와 간선 분할

S0는 침수 차단을 적용하지 않은 기준망이다. S1은 결합한 100년 빈도 국가·지방하천 위험지도에서 침수심 0.5m 이상인 구간을 대상으로 하고, S2는 0.5m 미만까지 포함한다. 이는 연구용 침수 시나리오다.

원본 방향 간선에서 침수 폴리곤 내부에 양의 길이로 겹친 구간의 시작·끝 누적거리를 저장했다. 차단 범위는 해당 자식 구간에 적용한다. 교량·고가는 평면상 겹침이 있을 때 별도 검토 상태로 기록한다. 침수 분할 경계에 생기는 노드는 방향마다 분리한다. 지도는 저장된 `start_m`, `end_m`으로 원래 방향 형상에서 해당 구간을 복원한다. 표시 전 단순화와 같은 OSM 선분 사슬의 역방향 중복 제거는 그림에만 적용한다.

## 시설 접속점 결정

적격 도로의 최근접 노드와 최근접 도로 형상 투영을 비교했다. 도로 형상 투영은 기존 노드 사이에도 고정된 접속 위치를 표현할 수 있다. @@DISTANCE@@

거리 이상치 16곳, 공간 검토 대상 2곳과 일반 시설 표본 12곳을 합해 30곳을 수동 검토했다. 지도에서 표시된 진입 위치를 근거로 필요한 경우 기존 적격 S0 도로 위 위치를 정밀 보정했다. @@SELECTION@@ 사용자가 검토에서 보고한 물리적 접근 불가 사례는 0건이다. 모든 최종 접속점의 좌표는 S0에서 정하며 S1·S2에서 같은 도로상의 위치를 사용한다.

## 검증된 시나리오 결과

@@RESULTS@@

도로 연장은 양방향 중복을 제거한 기존 물리 도로 차단 연장이다. 최대 SCC는 가장 큰 강연결요소에 남은 원본 노드 수다. 대표점 침수는 마스크 내부이며, 직선 접속선 교차는 폴리곤 내부에 양의 길이로 겹친 경우를 센다.

## 검증

독립 도로망 QA를 통해 방향, 분할, 길이, 상태 및 시나리오 간 포함 관계를 확인했다. 최종 시설 QA의 입력·출력 SHA-256과 시나리오 실행의 해시를 대조했다. HTML의 시설 상태와 통계는 검증된 분석 결과를 사용한다. 시설 좌표 및 방향별 도착 링크 집계가 해당 QA와 일치하는지 확인한 뒤 패키지를 생성한다.

## 해석 범위와 후속 분석

시설 대표점은 주소의 위치를 나타낸다. 대표점과 도로의 직선은 연구용 접속선으로 실제 진입로의 위치·고도를 제공하지 않는다. 침수 직선 교차는 별도 공간 지표다. 차량 진입 여부는 미확인 상태이며, 열려 있는 도로 접속점에서도 특정 출발점의 도달 여부는 이후 방향 그래프에서 판단한다.

후속 OD 분석은 기존 출발 노드와 시설 도착 전용 링크를 활용할 수 있다. 자식 간선 ID와 원본 간선의 부분 누적거리를 사용해 경로 길이를 결합하고, 차량·기상·도로 정보를 확보한 후 코스트를 정의한다. **간선별 코스트와 전체 OD 행렬은 아직 구축하지 않았다.** 입지 최적화는 별도 단계다.
